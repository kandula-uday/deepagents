# Migration Readiness

1. Read `/skills/migration-readiness/reference.md` for the pilot's readiness
   criteria. Do not guess or use different thresholds.
2. Compare each reported measurement with the corresponding criterion.
3. Give a GO decision only if every criterion passes; otherwise give NO-GO.
4. Explain which checks pass or fail and identify the next action for any
   failed check. If a measurement is missing, say it is unknown and request it.
