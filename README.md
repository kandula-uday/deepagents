# Deep Agents

This repository contains hands-on work with Deep Agents, focused on building
agents that can use tools, manage context, execute code, and involve people
in decisions.

It covers the following parts of an agent harness:

- **Execution environments:** Running code and working with files using
  filesystem backends, sandboxes, and a code interpreter.
- **Context management:** Giving agents instructions, managing conversation
  state, and maintaining memory across agent interactions.
- **Delegation:** Exploring how an agent can split work and pass tasks to
  other agents.
- **Steering and human-in-the-loop:** Guiding an agent with prompts and
  reviewing, editing, approving, or rejecting actions before they run.
- **Tools:** Connecting agents to custom tools, databases, and MCP servers.

The `homework` folder contains working examples and exercises. Other folders
are used for experiments, notes, and reference material. The repository is
being developed as I add more examples and explore additional capabilities.
